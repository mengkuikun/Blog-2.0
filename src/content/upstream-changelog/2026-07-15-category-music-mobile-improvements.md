## 分类页面重构

- 分类页面文章卡片从 `PostCard.astro` 替换为 `ArticleVirtualList.svelte`，与文章列表页保持一致
- 支持 list/grid 模式切换（骷髅开关）
- 支持封面图隐藏开关（`data-hide-covers`）
- 标签区域改为折叠展开，默认显示前 8 个高频标签
- 面包屑导航与标签筛选合并为一个卡片，减少多余间距

## 移动端文章页修复

- 修复移动端文章阅读页面顶部 ~88px 空白区域
- 提升 `mobile-dock.css` 中 `.no-banner-layout` 选择器特异性，覆盖 `layout-styles.css` 的 `top: 5.5rem` 规则

## 音乐页面优化

- 移除音乐页面主题切换逻辑（进入时强制暗色、离开时恢复），提升页面加载速度
- 移除 `<html>` 上的 `is-navigating-to-music` 和 `dark` 类的 SSR 注入
- 移除 Capture 阶段点击音乐链接时的暗色模式切换
- 移除 Swup `content:replace` 中离开音乐页时的主题恢复逻辑
- 音乐播放器添加返回首页按钮（`home-outline-rounded` 图标，位于下一首按钮右侧）

## 移动端播放器布局

- 音乐播放器控制区从横向三列改为上下三层布局
- 第 1 行：歌曲信息（封面 + 名称 + 歌手）
- 第 2 行：进度条
- 第 3 行：控制按钮（居中显示，包含音量按钮）
- 移动端音量按钮不再隐藏

## 应用展示页面

- 新增 `/apps/` 页面，展示使用过的应用和工具
- 复用友链卡片手绘风格，保留悬浮高度扩展动画（应用描述较长）
- 支持标签筛选和分页
- 在"关于"菜单下添加"应用展示"导航链接

## 友链卡片优化

- 友链卡片悬浮时去掉介绍框高度变化（2.2rem → 7.5rem），只保留阴影和圆角翻转动画

## 移动端导航栏优化

- Dock 工具按钮替换为暗亮模式切换按钮（太阳/月亮图标）
- 滚动隐藏 Dock 时，右下角显示浮动工具按钮
- 工具 Sheet 中新增"后台管理"入口（链接到 `/admin/`）
- 侧边栏菜单顺序调整：主页 → 网站导航 → 文章 → 动态 → 记录 → 关于

## Swup 过渡修复

- 修复从分类页面导航到文章列表页面后布局错乱的问题
- Swup `content:replace` 后派发 `swup:content:replaced` 事件
- `ArticleVirtualList` 监听事件重新初始化 grid 列数和移动端检测

## 说说独立评论

- 每条说说卡片底部添加评论按钮，点击后展开独立评论区
- 评论路径按 `moment.id` 独立存储（如 `/moments/2026-06-30/`）
- 使用 Waline 动态加载，首次展开时才加载 CSS/JS
- 展开动画使用 `grid-template-rows: 0fr → 1fr` 丝滑过渡
- 加载时显示骨架屏（闪光动画），Waline 渲染完成后淡入替换
- 评论区上方分隔线改为虚线
- 移除页面底部全局评论区
- 移除桌面端 FloatingDock 和移动端 MobileDock 中的评论按钮

## 应用展示页面优化

- 应用卡片点击不再跳转外部链接，只播放悬浮动画
- 从 `<a>` 标签改为 `<div>` 标签

## 更新日志页面

- 点击更新卡片可在卡片内展开详细 Markdown 内容
- 使用 `grid-template-rows: 0fr → 1fr` 丝滑展开动画
- 内容样式使用 `:global()` 确保动态渲染元素正确显示
- 展开时显示虚线分隔线

## 分类页面优化

- 去掉控制栏（骷髅开关 + 分类/归档按钮），页面更简洁
- 优化标签区域与文章列表之间的间距（2rem → 1rem）
- 分类页面 ECharts 图表（玫瑰图 + 标签图谱）改为懒加载，提升页面性能

## 侧边栏小组件升级

- 所有 WidgetLayout 组件添加圆角边框（10px）、朦胧阴影、hover 效果
- 个人资料卡片重建：视频背景（亮色/暗色分别对应不同视频）、圆形头像、社交图标
- 新增抖音热搜组件（`DouyinHot`）：自动获取热搜数据，前 3 名红色高亮，5 分钟缓存
- 新增天气组件（`Weather`）：自动 IP 定位，显示温度、天气、AQI、最高/最低温，气象预警轮播显示
- 恋爱小组件优化：头像间图标替换为 GIF，标题竖杠替换为 GIF，年月日分色显示
- 移除站点访问量组件（首页已有统计）

## 移动端导航栏优化

- 移除浮动按钮的桌面端溢出 bug（添加 `window.innerWidth` 检测）
- 浮动按钮组添加边框和毛玻璃效果

## 说说页面修复

- 修复 Swup 导航后评论按钮失效的 bug（添加防重复初始化机制）
