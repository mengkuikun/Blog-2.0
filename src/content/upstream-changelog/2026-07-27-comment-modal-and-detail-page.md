## 说说评论弹窗组件

- 新增 `CommentModal.svelte` 可复用评论弹窗组件
- 点击说说卡片评论按钮弹出苹果风格卡片，居中显示
- 使用 Waline REST API 自定义聊天 UI，不依赖 Waline 内置渲染
- 支持评论列表展示、回复引用、发送评论
- 用户信息（昵称、邮箱、网址）保存到 localStorage
- 有网址的用户昵称显示为绿色，无网址显示为黑色
- 输入框支持昵称、邮箱（方便接收回复消息）、网址（可选）

## 留言板风格聊天 UI

- 消息气泡使用留言板样式：深色背景白色文字
- 站长消息右对齐，白色背景深色文字，显示「站长」徽章
- 回复引用使用留言板的左边框样式，显示被回复内容预览
- 日期在消息上方居中显示
- 卡片整体 92% 透明度，背景遮罩 25% 黑 + 6px 模糊

## 说说详情页优化

- 详情页卡片宽度与列表页一致（去掉 max-width 限制）
- 卡片圆角与列表页一致（桌面 0.75rem，移动 0.625rem）
- 加载动画缩小为 200×80px，居中显示
- 加载时评论区收缩，加载完成后展开（grid-template-rows 动画）
- 加载动画最低显示 2 秒

## 加载动画

- 赛车动画使用 `var(--deep-text)` 颜色，适配深色/浅色主题
- 详情页：独立区域居中显示，加载完成后收起 + 评论区展开
- 评论弹窗：覆盖在消息区上方，加载完成后淡出

## 移动端优化

- 评论弹窗移动端：底部弹出，高度 72vh，只顶部圆角
- 输入框字段垂直排列
- 消息气泡 max-width 80%

## 修复

- 修复 Waline API 返回结构解析（双层 data 嵌套）
- 修复评论时间字段（time 替代 insertedAt）
- 修复嵌套回复展示（展平评论树 + 缩进）
- 修复评论按钮失效问题（client:load 替代 client:visible）
