## 架构重构与体验优化

> 💡 **致谢**：本次留言板重构深度参考并吸收了社区好友博主 **MmzMing**（[@MmzMing](https://github.com/MmzMing/my-blog) 在 commit `50a0edbff`）关于留言板回复取值与历史消息加载的高性能设计思路，并紧密结合本站专属的管理员审核工作流完成深度定制与融合。

### 1. 原生 pid / rid 回复机制与邮件提醒通知联动 (feature)
- **回复邮件提醒打通**：
  - 彻底告别以往通过正文内嵌 HTML 注释标记模拟回复引用的遗留方式；
  - 在 `src/utils/guestbook-chat.ts:388` 导出 `buildGuestbookReplyFields` 工具函数，回复时自动向 Waline 服务端传递原生数字型父评论 `pid` 与根评论 `rid`；
  - 成功触发 Waline 服务端原生的被回复者邮件通知链路：当访客的留言被他人回复且审核通过后，系统将自动向其留下的邮箱投递提醒邮件；
- **防 500 容错处理**：
  - 针对未填写邮箱的访客，提交评论时显式传空字符串 `""` 而非 `undefined`，规避 Waline 后端执行 Gravatar 解析时因 null 引发的 500 异常。

### 2. 留言板界面交互重构：本地滑动窗口与按需展开 (improvement)
- **轻量化顶部展开**：
  - 重构留言板长列表渲染架构，将默认视窗收敛为渲染最新的 20 条活跃消息；
  - 在聊天流顶部新增轻量直观的 `.guestbook-chat__reveal-older` 控制按钮，清晰显示当前隐藏的较早留言数量；
  - 点击即可秒级在本地展开历史消息，极大减轻初次进入及高频交流时的 DOM 负荷与渲染卡顿；
- **智能引用平滑跳转**：
  - 在 `src/components/features/GuestbookChat.svelte:1120` 优化了引用消息跳转算法：当用户点击的被引用消息处于未展开的历史折叠区时，系统自动动态计算并扩充视窗范围，随后平滑滚动居中定位至目标留言并伴随高亮提示。

### 3. 全量折半安全同步拉取机制 (improvement)
- **根治漏消息缺陷**：
  - 在 `src/components/features/GuestbookChat.svelte:720` 实现全量分批拉取策略（默认每批 64 条），并配套折半二分降级重试机制；
  - 彻底解决旧版本在传统分页模式下，新回复挂载在早期历史根留言底下、导致普通分页请求无法拉取到最新子回复的漏消息问题。

### 4. 深度融合管理员审核体系与国际化多语言对齐 (improvement)
- **管理审核能力完备与公屏权限隔离**：
  - 将 MmzMing 的轻量架构与本站定制的管理员专属审核能力完美结合：保留待审核消息列表抽屉面板、右下角审核入口微标小红点以及单条留言 Popover 三态切换（通过 / 待审 / 垃圾评论）；
  - **访客公屏权限隔离**：在 `src/components/features/GuestbookChat.svelte:106` 引入 `accessibleMessages` 派生过滤层，普通访客绝对隐藏他人未过审与垃圾留言，杜绝信息越权展示；
- **全语系对齐**：
  - 补全新增文案至全部 5 种支持语言（中文简体、中文繁体、英语、日语、俄语），保证各语种访客体验的一致性。

### 5. 纯表情与图片 Markdown 规范还原修复 (fix)
- **根治未登录访客视角下纯表情与图片变空白气泡缺陷**：
  - **根因分析**：Waline 后端为防止 XSS，仅向已登录的管理员下发原始 Markdown 字段 `comment.orig`，对普通访客仅下发服务端渲染好的 HTML `comment.comment`；此前使用的 `htmlToPlainText` 直接丢弃了 `<img>` 等标签节点，导致纯表情留言提取后变为空文本 `""` 并呈现为空白灰色气泡；
  - **规范还原**：在 `src/utils/guestbook-chat.ts` 中实现精准的 `htmlToMarkdown` AST 遍历转换器，将未登录时下发的 HTML 规范还原为 Markdown 图片与链接语法，并在动态与手账本聊天中同步复用，彻底拉平访客与管理员视角的表情渲染体验。
