## 后台管理 UI 改造

- 全新后台管理界面，零外部依赖，纯 CSS 手写
- **统一顶栏**：横跨整个页面宽度，显示页面标题 + 博客品牌名
- **深色侧边栏**：`#0f0f14` 深色背景，带微紫光晕，左侧 3px 紫色指示条标识当前页
- **侧边栏图标**：每个导航项前有图标（◉ 仪表盘、✎ 说说、▤ 笔记、⚭ 友链、▶ 影视、◎ 足迹）
- **暗色模式**：侧边栏始终深色不受影响，主内容区跟随切换
- **移动端适配**：侧边栏隐藏，顶栏显示汉堡按钮，点击下拉展开导航菜单

## 后台架构重构

- 新增 `AdminLayout.astro` 布局组件，所有后台页面共用
- 登录页独立（无侧边栏），登录后所有页面共享侧边栏
- 新增 `/admin/dashboard/` 仪表盘页面，Token 统一在此管理
- 子页面不再各自管理 Token，统一从 `localStorage` 读取
- 移除子页面的 Token 输入栏和连接状态栏

## 双栏布局改造

- 说说、友链、影视、足迹管理页面统一改为双栏布局
- 左栏：编辑/表单区
- 右栏：列表/数据区
- 桌面端左右各占一半，移动端自动堆叠
- 笔记管理保持全宽（编辑器需要宽度）

## 迁移脚本修复

- `gist-migrate` 新增 `places`（足迹）迁移支持
- 修复 `.env` 文件读取：脚本现在自动加载 `.env` 中的 `GITHUB_TOKEN`
- 修复 `readExistingIds` 正则 bug：`^# id:` 改为 `^id:`
- 足迹迁移格式统一：文件名只用日期，用 `date + city` 组合去重
- 数字标签自动加引号（`"2026"` 而非 `2026`）

## CLI 更新

- `pnpm cli gist-migrate` 新增 `places` 选项
- 帮助文本同步更新
